# 🐞 Code Debugger Game (Python)

A logic-based Python game where players debug and fix buggy Python code to pass levels and earn points.  
Built to improve debugging skills in a fun, interactive way.

---

## 🎯 Project Objective

The goal of this project is to help users:
- Practice Python debugging
- Understand common coding mistakes
- Improve logical thinking through hands-on problem solving

Instead of solving MCQs, players write real Python code.

---

## 🚀 Features

- 🧩 Multiple debugging levels  
- 🧠 Real Python code execution using `exec()`  
- ✅ Output validation for correctness  
- 📁 Clean, modular project structure  

---

## 🛠️ Tech Stack

- Language: Python 3  
- Concepts Used:
  - File handling
  - Dynamic code execution
  - Modular programming
  - Git & GitHub

---

## 📂 Project Structure

```
code-debugger-game/
├── main.py          # Game flow & user interaction
├── levels.py        # Buggy code levels
├── checker.py       # Code execution & output checking
├── utils.py         # Score handling utilities
├── requirements.txt # Project dependencies
├── .gitignore       # Ignored files & folders
└── data/
    └── scores.txt   # Stores previous scores (ignored in Git)
```
